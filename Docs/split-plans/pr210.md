8. **The API copy of those cases can skip.** `apps/project-car/api/tests/test_error_pages.py` shells out to node and calls `pytest.skip` when node is missing or cannot strip types. The web test already has the cases. A skip is not the proof. Do not carry this file.

12. **Encoded NUL still returns `/member`.** On the function in `b665069`, Node 22 gives `dashboardHref("/member/nope%00") === "/member"` because `%00` is not a raw control. The allowlist in slice 3 sends any `%` to `/`.
